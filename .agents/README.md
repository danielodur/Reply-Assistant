# Local Agent Skills

This directory contains project-local skills for AI agents working on Business Reply Assistant.

Use `SKILL.md` as the canonical Codex skill filename. Each skill is scoped to an actual recurring workflow in this repository and should be read only when relevant.

Current skills:

- `reply-assistant-workbench`: frontend workbench and Floating Assistant changes.
- `reply-assistant-generation-contract`: `/api/generate`, prompt fragments, providers, and API contracts.
- `reply-assistant-verification`: choosing and running the right verification commands.
